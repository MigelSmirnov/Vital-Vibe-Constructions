## Release integration

`tools/deploy/build-vps-bundle.mjs` generates all derivative families into `.deploy-dist/assets/responsive/` and patches only the generated ES/EN/RU homepage copies with `<picture>` + WebP width `srcset` + explicit `sizes`.

The original `<img src>` paths and intrinsic width/height remain as fallback. `<picture>` is layout-neutral (`display: contents`) so existing crop/object-fit CSS remains authoritative. No Media record is renamed or replaced.

The hero/LCP image remains deliberately outside these slices until measured separately.

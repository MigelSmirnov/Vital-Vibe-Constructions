# Homepage redesign sandbox

Visual prototype for the next Vital Vibe Construction homepage direction.

## Goal

Test a homepage that feels like a construction company with an engineering-office identity rather than a generic dark card-based template.

## Direction

- warm technical-paper palette with VVC yellow and black;
- asymmetric project-led hero;
- numbered sections and compact document metadata;
- services presented as a work schedule instead of cards;
- one featured case study plus supporting projects;
- technical domotics/electrical block;
- investment reference formatted as a specification table;
- technical-guides block that connects the homepage to the article-document system;
- contact area treated like a project title block.

## Status

Prototype only. `noindex` and not wired into `site-next`, sitemap, production routes, or the homepage builder. Use this branch to review the visual direction before implementing it through the generated-site architecture.
